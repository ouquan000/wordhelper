## 2 已定结论（带理由，不要推翻前先读理由）

### 2.1 结构只做「段落级」，不做任意布局

用户原话：「我最多加点小按钮和新的模块部分这一点你大可放心」。

- 能做：按顺序加/删/换模块、加按钮、改文案、改颜色
- 不做：自由绝对定位（像 PPT 拖到任意坐标）
- **理由**：手机屏幕宽度从 720 到 1440 都有，绝对定位换机必错位、文字重叠。顺序排列（搭积木）在任何机型都稳。

### 2.2 新按钮的「行为」必须预置在代码里

- 能下发：按钮出不出、放哪、文案、颜色、绑定哪个**已有**动作
- 不能下发：按钮点下去产生**全新行为**（那要发版）
- **理由**：App 只能执行它认识的动作。用户已知晓并接受。

### 2.3 拖拽 = 顺序排列，用户拖大概、我精修

用户原话：「我是拖到大概位置，然后你精修一下」「没问题，听你的，先做个简易的，而且可以拖动的简易的 也就是 b」。

- 编辑器里方块按**纵向列表**排列，可拖动改顺序
- 用户摆个大概，间距/字号/颜色由我方调
- **理由**：响应式天然成立；用户不懂代码，不需要精确到像素

### 2.4 编辑器是一个浏览器里打开的本地网页

用户原话：「我他妈不会写代码」「你给我整个小工具」「你就弄一个简易UI啥的，然后把它塞进 red me 里面，告诉后面的人有这玩意儿」。

- 形态：本地起一个网页，左边组件库、右边卡背预览、底部「预览 / 发布到手机」
- **必须写进 README**（用户明确要求，给后来接手的人看）
- 不用 Electron 独立 App（省一个安装包）

### 2.5 模型列表直接抄 DSH

用户原话：「直接把dsh上面的全部抄进去 就一样的 dsh的模型列表」。

- 1.4.3 做模型下拉时，选项与 DSH 右下角模型选择器一致
- 注意：DSH 的模型列表按 profile 分（desktop / web / headless 各不相同），做的时候要问用户抄哪一份

### 2.6 电脑常开；不在线时排队

用户原话：「我会一直开电脑，但是最重要的一件事情是，如果不开电脑的情况下，你要先保留这个要求，等到我开电脑再去做」。

- 重写标记：**先落本地库，再尝试发送**
  - 发送成功 → 提示「已发送」
  - 发送失败 → 提示「电脑不在线」，标记留在队列
  - 电脑上线后自动补发
- 加载/刷新：手机主动拉，**那一刻电脑必须在线**，离线只会提示「电脑没连上」，不会坏任何东西

### 2.7 两个按钮的位置

| 按钮 | 位置 |
|---|---|
| **刷新卡背结构**（圆圈带箭头，Material `refresh` 图标） | 词库页「当前词书：六级记忆卡」这一行**最右侧** |
| **重写思路** | 卡片**背面最底下**的组块（以后可在编辑器里调位置） |

用户原话：「那个刷新按钮也就是刷新背面卡结构的按钮 那个按钮放在我发给你那张图平行的最右侧」。

### 2.8 不破坏复习进度

- 卡背内容与 `tb_progress` 完全解耦，换结构不动进度表
- 新内容**盖上去**，不是换掉：加载失败/没网时退回旧版，卡片不能空

### 2.9 预览就在编辑器里

用户原话：「要的 但是在哪看呢 那个小编辑器吧怎么样」「1 要的」。

- 编辑器右边就是**实时卡背预览**，改一个字马上能看到
- 不另做预览窗口、不做「导出截图」

### 2.10 允许回退上一版

用户原话：「aaa 就这样 要允许回退 好的没问题就写交接文件和readme」→ 选 A。

- 手机端保留**上一次加载成功的版本**
- 加载新版后可一键「退回上一版」
- 加载失败时自动留在旧版，不提示报错吓人

### 2.11 重写范围由输入框决定

用户原话：「我会在那个框里面说，如果没有默认，就是记忆思路完全有问题，全部重写」。

- 框里写了什么，就按那句话重写（可以指出「第三句太扯」）
- **框留空 = 整段记忆思路重写**（这是默认值）
- 不需要做「选中句子」的交互

## 4 动效参考（用户指定，来自 Anki 老文件）

用户原话：「这个动效在anki老文件那里有很多个转场，还有正面反面切换的时候，文字的微错峰和反冲，你可以看一下，但是绝对不要上手」。

来源：`_compat_audit/render/cur-back.html`（V7 卡背渲染产物）

| 项 | 值 |
|---|---|
| 标题飞行 | `820ms`，`cubic-bezier(.22,.75,.2,1)` |
| 条目错峰 | `--stagger-gap: 90ms`（各条延迟 0/60/150/240/330/590/620/640/690/710/800/890ms） |
| 条目入场 | `220ms`，`cubic-bezier(.16,1,.3,1)`（easeOutExpo） |
| **反冲** | 关键帧 72% 处 `translateY(-1px) scale(1.0015)`，先冲过再回落 |
| 细节块 | `520ms` 淡入 6px |
| 音标 | 620ms 延迟，260ms 淡入 4px |

Compose 全部可复刻：stagger 用 `delay = index * 90`；反冲用 `keyframes { -1.dp at 0.72f }` 或阻尼 `spring`。
