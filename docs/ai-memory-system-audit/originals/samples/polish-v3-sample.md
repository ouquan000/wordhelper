## bit

**hint**
- 原：["bit 读 /bɪt/，短促干净的一个音节，收尾的 t 要轻。", "「一点」就是 bit：石板很大，她很小。", "拼写 b-i-t，一个音节，别和 bite 混淆。"]
- 新：["bit 读 /bɪt/，一个音节，收尾 t 要轻。", "石板高过头顶，她只到一半，这一半就是「一点」。", "拼写 b-i-t 三个字母，别跟 bite 混。", "大石板占满画面，人缩在底下，大小差就是「一点」。"]

**scene**
- 原："一块平坦石板立在画面里，上沿高过她的头顶，石板本身占据大部分画面；正面一侧她抬手贴住石板侧面，退开一侧她整个人缩小在画面下方仰头追着石板边缘，人和石板形成极大的比例差，画面只表达「整块石板」与「她的头顶只到石板一半以下」这个可见关系，读出「一点」的对比。"
- 新："一块平坦石板立在画面正中，上沿高过她的头顶，石板占去大半个画面。正面这一侧，她抬手把掌心贴平在石板侧面；退开的一侧，她整个人缩在画面下方，仰头追着石板边缘往上。她头顶只到石板一半以下，人和石板的比例差摆在眼前，画面只讲「整块石板」和「她这一点」的关系。"
