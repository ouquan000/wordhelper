## 3. B 标准：记忆设计的五条硬线（不合规 → 退回，不许改表达硬凑）

### B1 拆词粒度
拆到能单独挂上意义或读音的最小块；没有词根的短词整体记，不按字母拆。
**检查**：每个拆出的元素都被某条 hint 用到，且不只是复述这个字母怎么读。
- 正：teacher = teach（教）+ er（人）
- 反：b 读 /b/、i 短音、t 轻收 —— 每块都对，合起来不指向词义。

### B2 谐音只许一跳
读音或字形 → 中文词 → 词义，中间不许再借物。
**三项全过才算合规**：① 谐音词首音节声母韵母与原词一致；② 中文词直接通到词义；③ 不涉性/排泄/隐私/歧视。
- 正：ambition 谐「俺必胜」→ 雄心
- 反：ponder 谐「胖的」→ 胖子爱发呆 → 沉思（两跳）

### B3 hint 五勾
一条 hint 要把**一个画面元素**和**词义**绑在一起。
- □ 有英文词 □ 有中文义 □ 有一个画面里指得出来的名词 □ 有比较词或因果词 □ 遮住英文能从中文反推
- 一票否决：只讲读音、只讲拼写、「别和 X 混」但不给区别。
- 画面元素必须来自 `propEn` / `subjectAnchorEn`，**不许引入新道具**（引入 = 图文不符，红级）。

### B4 场景四层
只写：人物 1 个识别特征、道具、动作、承载词义的对比。
- 判：① 对比有参照物（「比她肩宽」而不是「很大」）；② 删掉某句后 hint 用到的元素还在 → 这句多余，删。
- 光照、季节、机位、表情，若不承载词义，删。

### B5 A/B 换角度（只用于校验 scene 是否贴合，不许改 action 句）
- 判：① 两句动词不同；② 人和道具的距离/高低/接触方式至少变一项；③ 变化让词义对比更明显；④ 两句都逐字含道具短语。

## 4. A 标准：中文表达的七条（逐条可打勾）

### A1 一句一动作
- 规则：一个分句只写一个动作或一个状态。
- 判：□ 每个逗号段/句号段 **≤12 字** □ 每段最多 1 个动词 □「的」前修饰最多 1 层
- 正：红发女生单手托着灰石板。石板比她宽，边缘在晃。
- 反：她用一只手托住头顶那块比她还宽的灰色石板。

### A2 删可删的修饰
- 规则：删掉后所指不变的形容词、副词一律删；只留大小、颜色、数量。
- 判：逐个遮住修饰词，说的还是同一个对象、同一个动作 → 必须删。
- 正：石板边缘在晃。 / 反：石板边缘还在轻微地晃动。

### A3 正确的废话
- 规则：不写「换成别的单词也成立」的句子。
- 判：把本词换成任一同类词，句子照样成立 → 删。
- 正：bit 的 i 和 sit 的 i 一样短。
- 反：短促干净的一个音节，收尾的 t 要轻。

### A4 看完等于没看的提示
- 规则：每条 hint 必须给出卡面上没有的具体信息。
- 判：□ 不复述单词和释义 □ 至少有一个具体字母、数字或对比项 □ 不写「注意」「别混淆」「记住」却不给区别
- 正：bit 短 i，bite 长 i，差一个 e。
- 反：「一点」就是 bit。／拼写 b-i-t，别和 bite 混淆。

### A5 翻译腔黑名单（出现即改）
「进行＋名词」「使得」「对于……而言/来说」「作为……」「通过……来」「在……的情况下」、
不表遭受的「被」、同句「他的/她的」出现 ≥2 次。
「这位、们、着」删掉后意思不变的，也删。
- 正：老师说话总带点不满，学生起初都不敢接话。
- 反：对于学生们而言，这位老师话里的不满使得他们不敢接话。

### A6 搭配只给意思
若 collocations 条目带中文：中文 ≤8 字，不用「表示」「意为」「指」。
- 正：bit by bit 一点一点地
- 反：bit by bit 表示事情慢慢发生变化

### A7 字数复核
拆完删完之后逐字段数一遍，超界即作废。

## 5. 两条标准的交叉冲突（执行时必须处理）

| 冲突 | 处理 |
|---|---|
| A1 要求每段 ≤12 字，但 `scene` 要 ≥50 字 | 拆成 **4–6 个短句**，合计落在 50–220：即「50 字是下限、12 字是每句上限」，两句之间不冲突，冲突只发生在「一句写到底」的写法上 |
| A6 要求搭配中文 ≤8 字，但 `collocations` 每条 ≥4 字符 | 英文短语本身即满足 4 字符；中文注释是附加，能删则删 |
| B3 要求 hint 提到画面元素，A3 要求句子不可替换 | 两个都满足的写法：**具体字母/数字 + 画面里的具体动作**（例：「bit 的 i 和 sit 的 i 一样短，石板压在她肩上」） |
| B4 要四层要素，A1 要短句 | 一层一句：人物一句、道具一句、动作一句、对比一句 |

## 6. 红黄绿判定表

| 现象 | 级 | 处置 |
|---|---|---|
| 引入 propEn 之外的新道具 | 红 | 退回 |
| 出现禁词（生动/有画面感/自然/流畅/优美/增强感染力/深刻/便于） | 红 | 退回 |
| 超字数 | 红 | 退回 |
| 输出含锁死字段 | 红 | 丢弃整条 |
| hint 条数不在 2–5 | 红 | 退回 |
| 谐音两跳以上 | 红 | 退回 |
| 只讲读音/拼写 | 黄 | 重写该条 |
| 单句 >12 字 | 黄 | 拆句 |
| 出现翻译腔黑名单词 | 黄 | 改写 |
| 三条 hint 说同一件事 | 黄 | 合并重写 |
| 改完更短、信息量不降 | 绿 | 接受 |

## 7. 程序断言（不靠模型自觉）

```python
ALLOWED = {"hint", "scene", "exampleZh", "collocations"}
LOCKED  = {"elements","method","split","derivation","propEn","subjectAnchorEn",
           "styleAnchorEn","actionAEn","stateAEn","actionBEn","stateBEn",
           "imagePrompt","imagePromptA","imagePromptB","word","phonetic","pos","meaning"}
BANNED  = ["生动","有画面感","自然","流畅","优美","增强感染力","深刻","便于",
           "进行","使得","对于","而言","作为","通过","情况下"]

assert set(out) <= ALLOWED, "越界字段"
assert not (set(out) & LOCKED), "碰了锁死字段"
assert 2 <= len(out["hint"]) <= 5
assert all(2 <= len(h) <= 32 for h in out["hint"])
assert 50 <= len(out["scene"]) <= 220
assert 4 <= len(out["exampleZh"]) <= 200
assert 2 <= len(out["collocations"]) <= 4
assert all(4 <= len(c) <= 80 for c in out["collocations"])

blob = json.dumps(out, ensure_ascii=False)
assert not any(w in blob for w in BANNED), "命中禁词"
# 单句长度：按 [。！？；,] 切分，每段 ≤12 字（A1）
for seg in re.split(r"[。！？；,，]", out["scene"]):
    if seg.strip():
        assert len(seg.strip()) <= 12, f"单句过长: {seg}"
# 道具白名单：hint/scene 里出现的 "石板/绳子/木桩" 等必须映射回 propEn
```

## 8. 对照样张（bit / 一点）

**before**
```
hint:
1. bit 读 /bɪt/，短促干净的一个音节，收尾的 t 要轻。
2. 「一点」就是 bit：石板很大，她很小。
3. 拼写 b-i-t，一个音节，别和 bite 混淆。
scene: 秋天林荫道上，红发女生单肩挎着棕色皮包，用一只手托住头顶那块比她还宽的灰色石板，石板边缘还在轻微晃动，她侧头看向镜头，表情平静。
exampleZh: 这位老师说话总带着一点不满，学生们一开始都不敢接话。
collocations: a bit of luck / a little bit / bit by bit
```

**after**
```
hint:
1. bit 的 i 和 sit 的 i 一样短。
2. bite 多一个 e，i 就变长：bit 是一点，bite 是一口。
3. 石板压得她只剩一点空间。
scene: 红发女生单手托着灰石板。石板比她还宽。边缘在晃。她侧头看镜头。石板压得她肩膀下沉。
exampleZh: 老师说话总带点不满，学生起初都不敢接话。
collocations: a bit of luck 一点运气 / a little bit 一点点 / bit by bit 一点一点地
```

数一下 scene：`红发女生单手托着灰石板。`(11) + `石板比她还宽。`(7) + `边缘在晃。`(5) + `她侧头看镜头。`(7) + `石板压得她肩膀下沉。`(10) = 40 字 + 标点 5 = 45 —— **不够 50**，需再补一句短句（例：「秋天，林荫道。」），这正是 §5 冲突表要防的坑。
