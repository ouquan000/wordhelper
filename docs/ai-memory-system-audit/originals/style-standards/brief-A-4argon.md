我们要给「英文单词记忆卡」定一份**中文表达**的润色标准。你只看中文写得好不好，不用管记忆法设计（那部分另有模型负责）。

【使用场景】
Anki 卡片背面，使用者是中国六级考生。卡片上先出现英文单词和释义，然后依次出现 4 条「学习思路」、一个图片轮播、一个「记忆钩子」。全部内容在手机上以窄栏显示。

【四个可改字段 + 字数硬上限】（超字数会被程序直接拒收，等于这条改写作废）
- hint：记忆提示，2–5 条，每条 2–32 个字符
- scene：场景描述，50–220 字符
- exampleZh：英文例句的中译，4–200 字符
- collocations：常用搭配，2–4 条，每条 4–80 字符

【一张真实卡片的现状原文（词：bit，释义：一点）】
hint：
1. bit 读 /bɪt/，短促干净的一个音节，收尾的 t 要轻。
2. 「一点」就是 bit：石板很大，她很小。
3. 拼写 b-i-t，一个音节，别和 bite 混淆。

scene（127 字符）：
秋天林荫道上，红发女生单肩挎着棕色皮包，用一只手托住头顶那块比她还宽的灰色石板，石板边缘还在轻微晃动，她侧头看向镜头，表情平静。

exampleZh：
这位老师说话总带着一点不满，学生们一开始都不敢接话。

collocations：a bit of luck / a little bit / bit by bit

【你的任务】
写出「什么算好中文」的可执行标准，让另一个较弱的模型能照着改。

【硬性要求】
1. 每条规则写成：规则 → 判定标准（能打勾的、二值可判的） → 正例 → 反例
2. 反例必须是「看着挺顺但其实是废话/记不住」的那种，不要写成明显病句
3. 禁止出现无法判定的词：生动、有画面感、自然、流畅、优美、增强感染力（出现即视为不合格）
4. 只谈这四个字段的中文表达，不要评论记忆方法、不要建议加字段、不要建议改结构
5. 重点回答：中文长句该拆到多短；形容词副词什么时候必须删；什么叫「正确的废话」；什么样的提示语看完等于没看；中译里哪些词是典型翻译腔（比如「进行」「使得」「对于……而言」）
6. 全文不超过 600 字，只输出标准本身，不要前言和总结
