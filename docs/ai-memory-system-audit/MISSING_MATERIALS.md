## 1. 任务书点名要找、但**确实不存在**的

### 1.1 「熟词桥接」规则 —— 不存在

**找过的地方**：`app/src_repo/app/src/main/`（kt/json）、`docs/`、`tools/`、`review/` 全部 `.kt/.md/.txt/.py/.json`，`Select-String -SimpleMatch "熟词桥接"`。
**结果**：**0 命中**（全仓库源码与文档范围内）。

**成因判断（据现有文件）**：六脉神剑六招里没有「熟词桥接」这一招。最接近的两个东西是：
- `mnemonic-reference.txt` L9 的 `polysemy` 熟词生义法 —— 是「熟词在特定语境下的新义」，不是「用熟词去桥接生词」；
- `generate.txt:3` 的学习者画像「高考 3500 + 四级已背完，**基础词当锚点，绝不解释基础词本身**」—— 这是一种「拿熟词当锚点」的用法，但它只是**一句话的画像要求**，没有成文的桥接方法、判定标准或示例。

**结论**：如果 GPT 要审「熟词桥接」，仓库里**没有可审的对象**。要么这份标准从未写下来，要么它在别处（本机其他目录）而本次未找到。

### 1.2 「场景联想」作为独立规则 —— 不存在（只剩字段级遗迹）

**找过的地方**：同上。
**结果**：全仓库只有 **2 处**提到「场景联想」，且都不是标准：
1. `app/src_repo/app/src/main/java/com/kaoyan/wordhelper/util/PromptTemplates.kt:60` —— 提示词模板里的一个**占位符**：`<一句话谐音或场景联想>`（App 内 AI 助记面板的三段式之一，≤120 字）。
2. `app/src_repo/app/src/main/assets/cet6_cards.json`（83867 行量级）—— 成品卡片文本里出现的自然语言。

**为什么不能算「场景联想标准」**：
- 真正成体系的场景规则有两份，但都**不在运行中**：`mnemonic-reference.txt` L20–23（三板斧）与 L37（scene 100–200 字）+ Grok 的 G6–G9（scene 只写可见物、50–220 汉字、只靠已画出的比例/姿势/空制造张力）。这两套的**字段 `scene` 在 App 运行时根本不存在** —— `generate.txt` 开篇就写「不写例句、不写配图提示词、不写场景描写 —— 那些环节这个 App 不用」。

**结论**：场景联想在**历史标准里有、在运行中没有、在 App 里只剩一个模板占位符**。三者都不是同一份东西。

### 1.3 「从英文线索回钩词义、记忆闭环」的独立标准 —— 没有成文，只以判据形式存在于 judge

**找过的地方**：`回钩` 全仓库 **0 命中**；`闭环` 184 命中，但绝大多数是 judge 维度别名「链条闭合」以及与本任务无关的 `dsh-*` 文档。

**它以什么形态存在**：`prompts/judge.txt:1–4` 的四句话——
> 记忆质量优先；必须说明画面线索如何回到目标词、如何回到词义；不得声称场景自动推出拼写；熟词拼接仅记忆技巧不得冒充词源；**语义推理最多两跳**。

这是**唯一**一处把「回钩」写成可判定要求的地方，而且它是**评委的判据**，不是**生成方的写作规范**。生成侧对应的只有 `generate.txt` 的「末行必须用「——>」落到中文词义」和 `pipeline.normalize()` 的机械校验（末行必须含箭头）。

**结论**：不存在一份叫「记忆闭环标准」的文档。闭环要求被拆散在「生成一句 + 评委四条」里。

## 3. 数据层面缺的东西（影响「能不能证明有效」）

**没有任何一份**：复习间隔、遗忘曲线、「模糊 / 不认识」的点击记录、同词再重写率的时间序列。

这些数据在 App 的 Room 数据库里（`tb_review_*` 之类），**不在本仓库，也没有导出**。
**后果**：本归档只能评估「用户当场喜不喜欢这条思路」，**完全无法评估「记住没记住」**。任何关于「记忆效果」的结论都必须止步于此。

### 3.2 一次真正的 **A/B / 跨词偏好实验** 都没有跑过

`HANDOFF.md §9`「用户点名的方向：个性化生成」（2026-11-08 01:29）明确写「**尚未开工**」，只有计划：
> 喂数据（approach + 三键评分 + 复习间隔/遗忘 + 抱怨原文 + 保留/撤销）→ 学画像 → 只改生成/润色 → 影子 A/B 看撤销率 / 同词再重写率 / 模糊+不认识占比。

**现状**：计划里的数据（三键评分、复习间隔、遗忘、撤销记录）一项都没进管线；影子 A/B 从未搭建。
**所以 `experiments/` 里全是回顾性统计，没有一条是干预实验** —— 这不是漏找，是本来就没做。

**结论**：这批全量润色的质量从未被度量过（详见 `experiments/03-offline-polish-batch-20261105.md`）。
