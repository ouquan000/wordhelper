# 1.4.7 更新公告（大白话版）

这次是「远程同步专版」，但先说清楚：**公网远程还没开**，现在仍然要手机和电脑在同一个 WiFi。这版真正做的事是——连不上的时候你能看见卡在哪、换地址不用重启 App、换电脑不会悄悄漏数据。

## 你能感觉到的

**1. 多了一个「同步状态」页（入口：我的 →「同步状态 ›」）**

在「同步学习记录」按钮下面多了一行。点进去能看到：现在连没连上、上次成功是什么时候、还有几条没发出去、下次重试倒计时几秒、实际连的是哪台电脑、电脑端的版本和启动时间。

失败时不再是干巴巴一句「同步失败」，而是分得清：

- **「电脑端版本过旧」**——只在电脑端还跑着旧进程时出现（HTTP 404）。这时去电脑上重启一次服务就好。
- **「需要口令 / 口令不对」**——只在连接串里的口令和电脑对不上时出现（HTTP 401）。重贴整行连接串。
- **「请求太频繁」**——只在短时间反复点「立即重试」被限流时出现（HTTP 429）。页面会显示还要等几秒，别连点。

**2. 改完地址立即生效**

以前改完地址要杀掉 App 重开才真的换过去，现在保存后点「立即重试」就走新地址。

**3. 换电脑、重装，不再悄悄漏数据**

以前换到另一台电脑，手机还拿着旧进度，会出现「显示已连接，但少了几天的记录」。现在地址一变就自动从头对齐。

**4. 冷启动更快**

以前每次杀进程后第一轮都整包拉一遍（现在约 57KB），现在只拉新增的那部分。

**5. 地址框防手滑**

多行粘贴只取第一行。以前把整段诊断文字粘进去会解析失败，然后悄悄退回上次的地址，看着像「新地址也连不上」。

## 两件需要你动手的

1. **重贴连接串**（口令换了，旧口令现在会 401）：`http://10.105.85.227:8765#<口令>`。口令在电脑端窗口打印的那一行里；手机「我的 → 卡背结构地址」整行粘进去。
2. **底部导航里的「查词」按你的要求摘掉了**：现在只有 学习 / 词库 / 我的。查词页本身还在，以后想加回来只是一行的事。

## 升级注意

- 覆盖安装就行，学习进度不动。
- 设置里版本号**仍然显示 1.4.6.2**——这次故意没改版本号，别以为没装上。
- 电脑端 8765 已经重启过了；哪天电脑重启，照 runbook 把服务拉起来即可。

## 还没有的（别当成 bug）

- **公网远程（4G / 外面 WiFi）还没开**：隧道没配，现在仍要求同一个 WiFi。那是下一步。
- 这版只在模拟器上验过，**还没上真机**。
- 多设备合并、冲突解决仍然不做（1.4.7 只做单手机 + 单电脑）。

## 三句话版

1. 多了「同步状态」页，连不上能看见卡在哪一步。
2. 换地址立即生效、换电脑不漏数据、冷启动不再全量拉。
3. 口令换了要重贴一行；公网远程还没开，仍要同一 WiFi。
