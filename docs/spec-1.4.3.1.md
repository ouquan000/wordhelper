## 2. 改了什么

| # | 改动 | 关键实现 |
|---|------|----------|
| 1 | 重写条从卡片外挪进卡背内部最下面 | `LearningScreen.kt` 的 `WordCard` 新增 `backActions` 槽；内容 `!showFront` 才渲染；吞掉空白点击，避免误触发翻面 |
| 2 | 只在背面显示 | 传 `isCardFlipped`，正面不占高度 |
| 3 | 真实进度条 | 服务端 `store.py` 记录 `stage`；手机 `statusOf()` 取状态，映射 8/45/75/92/100%，失败停在当前值变红；卡背可见且标记未完成时 4 秒轮询 |
| 4 | 翻面即同步 | `syncRewriteOnBackFlip()`，8 秒节流，避免来回翻面打爆电脑 |
| 5 | 终态原地换文 | 终态同步条件从「本会话未同步过」改为「当前标记未完成」，并 `key(word.approach)` 强制卡背内容随新文本重建 |
| 6 | 删 EF 系数因子 | 不再渲染 `EF_STATS`（`-> Unit`，兼容旧配置）；内置默认清单与已发布清单（revision 36）都去掉该块 |
| 7 | 电脑端记录页 | `GET /rewrite`（页面）、`GET /rewrite/records`（JSON，limit/offset）；卡背编辑器首页加入口 |

## 3. 验收方式

- 模拟器 `emulator-5554` 手工冒烟：正面无重写条 → 翻面出现且贴卡底 → 点重写 → 进度 75% → 100% → **不翻面文字原地更新**（实测 rev 9，文本从「先看 appropriate 的骨架…」换成「看骨架：appropriate 切成 ap-propri-ate…」）→ 撤销恢复上一版。
- DB 证据必须带 `-wal` 一起拉取；只读 `.db` 会读到旧快照（本项目已知坑）。
- 独立测试 agent 报告：`docs/test-report-1.4.3.1.md`。
- 独立评分 agent 报告：`docs/review-1.4.3.1.md`。

## 4. 已知限制（不阻塞）

- `portdan-grok` 串行后单条 5–10 分钟；`portdan-gpt` 有些词两轮都判不过（质量判罚，原卡不动）。
- 换机/重装恢复：首次启动若遇到 HTTP 截断会丢掉这一页（不推进 `since`，下次回前台重试，最多 3 次）。
- 撤销只能回一版，多设备之间不同步。
- 8765 监听 `0.0.0.0` 且无鉴权：同网段可读全部改写结果、可替任意词提交标记；只应在家里内网用，不要暴露公网。
