# 1.4.7 远程同步决策记录（草稿）

> 2026-11-09。**尚未实施**，只记录已定的取舍与待验证项。
> 现状与计划见 [`../HANDOFF.md`](../HANDOFF.md) §15；用户版说明见 [`../README.md`](../README.md)「远程同步（1.4.7 方向）」。

## 0 一句话

把 8765 从「同 WiFi 的局域网服务」变成「手机在任何网络都能连的 HTTPS 服务」：
Cloudflare Tunnel + `anki.ouquansdiary.cn` + token + 限流；App 侧只加连接串、状态页与可靠重试。

## 1 通道选择

| 方案 | 手机端 | 成本 | 风险 | 结论 |
|---|---|---|---|---|
| Cloudflare Tunnel | 不用装东西 | 域名 38 元 + CF 免费档 | `.cn` 备案 / 被墙；登录与 NS 变更要用户本人 | **主方案** |
| Tailscale Funnel | 电脑装 Tailscale，手机不用装 | 免费 | 国内连通性 / 带宽待实测；电脑需常驻 | 备选，不默认 |
| 换非 `.cn` 域名 | 不用装东西 | 域名年费 | 多花钱；仍要过 CF | 域名走不通时用 |

选择理由：

- **不改 App 也能先验证**：现有 `base#token` 连接串在 HTTPS 下语义不变。
- **手机零安装**：手机端不用装任何客户端；Tailscale Funnel 也只在电脑侧装 Tailscale。
- **可回退**：隧道挂了还能回局域网地址；App 记住「上次成功 + 候选」。

## 2 鉴权与限流

- token 走 URL fragment（`https://host#token`），App 拆出来放请求头；不进查询串、不进日志。
- 2026-11-09 已修：`_is_local()` 仅 `loopback peer` 且无 `CF-Connecting-IP` 才免票
  （`tools/cardback-editor/server.py:863`）。五组请求已验证（本机 / CF 头 / LAN × 有无 token），
  见 HANDOFF §15.3。
- 429 必须能看懂：状态页显示「被限流，X 秒后重试」；App 指数退避，禁止 4 秒死循环。
- token 轮换：只换一端会 401；runbook 要写「电脑生成新 token → 手机重粘整行」。

## 3 域名与备案取舍

- `ouquansdiary.cn` 已在腾讯云购买、实名通过；**注册局 1–2 个工作日恢复解析**（截至 11-09 未恢复）。
- 本机 `anki.ouquansdiary.cn` → `198.18.0.180` 是代理假 IP，不算解析成功。
- 风险：`.cn` + 国内宽带公网 Web 可能被要求 ICP 备案，也可能被墙；**先技术验证，不先承诺长期可用**。
- 若验证失败：换非 `.cn` 域名 > Tailscale Funnel（仅电脑侧装）> 回局域网。

## 5 不做

- 多设备合并、冲突解决（1.4.7 只做单手机 + 单电脑）。
- 手机装客户端的私有组网（Tailscale Funnel 是公网入口，不在此列）。
- 为了远程同步重写 SRS / 同步协议。
- UI 八条、root 尾注、动效（另开版本）。
