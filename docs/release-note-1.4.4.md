# v1.4.4 更新公告

## 短版（发群里用）

背单词 App 更新到 1.4.4：卡背音标旁多了个「记忆方法」小标签，告诉你这个词是靠联想、谐音还是词根记住的；学习统计多了「全局 / 当前词书」切换和方法分布；学习记录现在能一键备份到自己的电脑，平时完全离线。覆盖安装就行，进度不丢。

---

## 长版（App 内 / 公众号）

**这次更新不大，但都是背词时真会碰到的事。**

**1. 卡背会告诉你「这词用的是什么招」**
音标旁边多了个小标签：联想 / 谐音 / 字形 / 词根 / 对比 / 多义。
六级 5228 个词已经全部标好；你点「重写思路」换了新思路，标签也会跟着换。

**2. 统计能按书看了**
学习统计右上角多了「全局 / 当前词书」两个切换按钮，下面还多了一行「按记忆方法」分布——看看自己更吃哪一种招。

**3. 学习记录能备份到电脑了**
我的 → 数据管理 →「同步学习记录」。
平时它完全离线，只有你点那一下才连电脑；第一次点会把这之前背过的进度也一起推上去。电脑端开着卡背编辑器就行。两边记录冲突时按「最后复习时间」自动判，不弹窗。

**4. 词库清爽了**
两本 5000 多词的大词库默认藏起来，词库页不再一进来就是一排用不上的。想用可以在设置里开回来（下次启动生效）。

**5. 重写的思路更像人话了**
不再硬凑三行：3–5 步把话说清楚，允许一点冷幽默和双关，但不动发音、不动意思。

**6. 电脑端加了口令**
手机填一次，防止同一网络下别人乱动你的卡背。在电脑本机开浏览器不用填。

---

**升级注意**

- 直接覆盖安装，学习进度不会丢。
- 第一次打开会升级一次数据库、补一遍标签，几秒钟，别急着关。
- 电脑端脚本有更新，记得把旧的关掉重开一次。

**几个已知的小遗憾（不藏着）**

- 测试·20词、新加的生词，要重写过才有标签。
- 撤销只把正文撤回去，标签不跟着回滚。
- 按书统计目前只能看「当前词书」，还不能在几本书之间随便切。
- 大词库开回来要等下次启动，第一次导入大约 30–60 秒。

有问题直接说，能修就修。
