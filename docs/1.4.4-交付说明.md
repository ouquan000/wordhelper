# 1.4.4 交付说明（2026-11-08）

包：`dist/english-app-1.4.4.apk`（versionCode 9 / versionName 1.4.4 / DB 16，33,422,765 B）

## 这版能用的新东西

1. **卡背音标旁多一个小胶囊**（联想 / 谐音 / 字形 / 词根 / 对比 / 多义）——六级记忆卡 5228 词已全部补好；重写成功后标签会跟着换成新方法。
2. **学习统计右上角多两枚按钮「全局 / 当前词书」**——全局仍是原来的「次」，当前词书是这本书的去重「词」；卡片底部多一行「按记忆方法（已学 N 词）：…」。
3. **我的 → 数据管理 →「同步学习记录（N）」**——平时纯本地，点了才跟电脑对一次；冲突按「最后复习时间」自动判，不弹窗。电脑端要先开着卡背编辑器。**第一次点会把这之前背过的词也一起推上去**（不只是从今往后），换机前点一次就行。
4. **两本内置大词库默认隐藏**——设置里可以开回来（**下次启动生效**）；词库页只剩「六级记忆卡 + 测试·20词」（+ 生词本）。
5. **重新生成的思路更长、更像人话**：3–5 步、不再卡每行字数；润色带口吻，允许冷幽默/双关，但不改音、不改义。
6. **电脑端 8765 加了口令**——手机设置里填电脑启动窗口显示的「手机口令」；本机浏览器访问不用填。

## 已知限制

- 标签只覆盖六级记忆卡的 5228 词；测试·20词、新建的生词词条要等重写过才有标签。
- 撤销只回滚卡背正文，不回滚方法标签。
- 按书视图只能看「当前词书」，没有书目选择器；要看另一本的统计要先切当前词书。
- 同步只搬学习进度（复习状态/间隔/到期时间），不搬卡背改写版本。
- 打开「显示内置大词库」后首次导入要 30–60 秒，期间词库页可能短暂显示 0 本。

## 升级注意

- 覆盖安装即可（同签名 / 同包名 / 版本号 9 > 8）；首次启动会做一次数据库升级（15 → 16），只加列和加表，不删数据。
- 电脑端脚本有更新：重启一次 `tools/cardback-editor/server.py` 才会带上同步接口和新口令校验。
