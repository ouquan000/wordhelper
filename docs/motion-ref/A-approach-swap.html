换文

卡背被整段重写后，三行推导逐行替换：旧文先退，新文从下方 10px 处淡入归位。数字 ①②③ 不动，只换内容——动的是文字，不是版面。

meticulous

/məˈtɪkjələs/
释义

adj. 一丝不苟的；极为仔细的

记忆思路
①

met 来自拉丁语 metus，本义是「怕」。怕出错，才会抠到每一处。

②

所以 meticulous 不是「认真」，是「怕到不敢放过任何细节」。

③

画面：交卷前把答题卡擦了三遍，还是觉得不干净的那个人。

重写思路 DeepSeek V4.1 Flash ▾

模拟重写完成后的整段替换 · 留空＝整段重写

打开后自动换一次；再按「重播」会换回另一组。慢放只是把同一段动画拉长，不改曲线与位移。

参数

逐行错峰
140 ms
旧文退出
120 ms · −6 px
新文入场
300 ms · +10 px → 0
缓动
cubic-bezier(.23, 1, .32, 1)
入场模糊
1.5 px → 0
末行结束
≈ 720 ms

Compose 示意

val enter = fadeIn(tween(300)) +
    slideInVertically(tween(300)) { 10.dp }
val exit  = fadeOut(tween(120))

Row {
  // ① ② ③ 固定；只让正文 AnimatedVisibility
  AnimatedVisibility(visible = shown, enter = enter, exit = exit) {
    Text(line)
  }
}
// 每行 delay = index * 140ms，先出后进，串行

为什么这样

  • 数字不动。①②③ 是行的锚点；它们一跳，观感就从「文字在换」变成「整块在闪」。
  • 同一行先退后进。两段不同文字若同时占同一块像素，会短暂重影；串行 40ms 就够错开。
  • 位移只有 10px。再大就像卡片在动。淡入占主导，位移只负责「从下面落位」的方向感。
  • 只错峰三行。错峰能让眼睛顺着 ①②③ 读完；行数再长就会显得慢。
