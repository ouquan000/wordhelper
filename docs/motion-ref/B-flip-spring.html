meticulous

/məˈtɪkjələs/

先别翻：metus 和「怕」
能拼出什么关系？

点一下看卡背⤾
卡背 记忆思路
释义

adj. 一丝不苟的；极为仔细的

记忆思路
①

met 来自拉丁语 metus＝怕；怕出错，才会抠到每一处。

②

不是「认真」，是「怕到不敢放过任何细节」。

③

画面：交卷前把答题卡擦了三遍的人。

点一下翻回正面⤿

打开后自动翻一次；点卡片可来回翻，中途再点会带着速度反向。慢放只拉长时间轴，过冲量不变。

参数

阻尼比 ζ
0.82
刚度 / 质量
stiffness 200 · mass 1
旋转
0° → 180°（仅 rotateY）

Compose 示意

val angle by animateFloatAsState(
  targetValue = if (back) 180f else 0f,
  animationSpec = spring(
    dampingRatio = 0.82f,   // 0.8–0.9
    stiffness = 200f      // mass = 1
  ), label = "flip"
)
Card(Modifier.graphicsLayer {
  rotationY = angle
  cameraDistance = 12f * density
})

为什么这样

  • 过冲是结果，不是参数。ζ=0.82 时二阶欠阻尼的峰值为 1.1%，180° 上就是 2°——看得出「落定」，但不至于晃。
  • 只转一个轴。晕来自多轴叠加和长尾摆动；这里 X/Z 恒为 0，稳定后直接停。
  • 阴影跟着 |cosθ| 收窄。90° 边缘对齐时阴影也变成一条线，这一下让翻转「有厚度」。
  • 可打断。中途再点，弹簧带着当前速度反向，不会从头播一遍——这是 CSS keyframes 做不到的。
