怎么看

  1. 三个页面打开后都会自动演示一次，不用先找按钮。
  2. 要反复对比就按重播；拿不准节奏时开慢放 ×2.5，曲线和位移不变，只拉长时间轴。
  3. B 的卡片可以直接点，翻到一半再点会反向——这一下最能看出是不是弹簧。

判断标准

不看「有没有动画」，看三件事：文字有没有重影（A 的旧文/新文是否抢同一块像素）、落定有没有回弹感（B 的 2° 过冲是不是刚好）、出现时正文有没有被顶一下（C 是否只动 transform / opacity）。

方法论来自 Open Design 的 animate / emil-design-eng / emilkowalski-motion 三份 skill：进入用 ease-out、只动 transform 与 opacity、位移量控制在「看得出方向但不像在弹」的范围内；滚动入场只播一次，避免跟读者抢注意力。
