appropriate

/əˈprəʊpriət/
释义

adj. 恰当的，合适的

记忆思路
①

propri 是「自己的」；把别人的东西划到自己名下，就是「挪用」。

②

把话说得正好落在它该在的位置上，就是「恰当」。

③

拆：ap + propri + ate；先有「归属」，才有「合适」。

常用搭配

appropriate for  对…合适

appropriate to  适用于

例句

Wear something appropriate for the occasion.

穿适合这个场合的衣服。

同根词

property 财产  ·  appropriation 拨款；挪用

打开后会自动滚到重写区演示一次；也可以自己滚。「重播」= 回到卡背顶部，再滚一次（模拟新一张卡）。

参数

触发
IntersectionObserver · 可见 18%
滚动容器
卡背内部 .scroller
时长
460 ms
位移
+12 px → 0（向上归位）
缓动
cubic-bezier(.23, 1, .32, 1)
重复
每条卡只播一次

Compose 示意

var shown by remember(cardId) { mutableStateOf(false) }
// LazyListState 里判断「该条首次进入视口」，只置一次
LaunchedEffect(cardId) { shown = true }

AnimatedVisibility(
  visible = shown,
  enter = fadeIn(tween(460)) +
          slideInVertically(tween(460)) { 12.dp },
  exit = ExitTransition.None     // 不进不退，出现即留下
) { RewriteBar() }

为什么这样

  • 只动 transform / opacity。重写区一直占着布局位置，出现时不会让正文重排、滚动位置跳一下。
  • 12px 要小。再大就变成「弹出来」；12px 只够给一个方向感——它从下面来，不是凭空出现。
  • 只播一次。每次滚过都淡入，等于反复跟读者抢注意力；一张卡看一次就够。
  • 460ms 比控件长。这是内容入场，不是按钮反馈；但它仍要在你读完之前完成，所以不拖过 0.5s。
