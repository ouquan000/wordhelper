# 重写用不了：诊断与杜绝（1.4.5）

## 一句话

不是重写坏了，是**手机里存的电脑地址过期了**：电脑下午换了 WiFi 分配（`10.105.85.173` → `10.105.85.227`），手机还在往旧地址发；同时电脑端从 15:58 起要求口令。两件事叠在一起，手机每次只能弹「已记下，等电脑连上再发」。

## 证据（电脑端，不用碰手机）

| 看什么 | 看到什么 | 说明 |
|---|---|---|
| `tools/cardback-editor/server.log` | 15:58 重启后**一条真机的 `POST /rewrite/marks` 都没有** | 请求根本没到电脑 |
| 同上 | 只有编辑器自己的 `/api/state` | 电脑端服务是活的 |
| `sync.json` / `queue.json` | 真机设备号 `a891b57a…` 一次没出现 | 不是「到了但被拒」 |
| `curl /models` 不带口令 | `401 token_required` | 口令闸在工作 |
| 带 `X-Cardback-Token` | `200`，5 个模型 | 电脑端健康 |
| 电脑 WLAN 日志 | 13:08 换租约 `10.105.85.173 → 10.105.85.227` | 手机里的地址过期 |

模拟器上复现不出「口令错」，因为模拟器经 `10.0.2.2` 到宿主时源地址是 `127.0.0.1`，本机免票——这是测试盲区，不是功能正常。

## 修（真机，需要一条 adb 通道）

前置：手机和电脑同一个 WiFi（`10.105.85.x`）。

1. 取证（30 秒，只读）：读出手机里存的地址与口令，判定是「地址旧」还是「没口令」。
2. 备份：`am force-stop` → 拉 `databases/kaoyan_words.db` 三件套到 `_backup/realdevice-<日期>-rewritefix/`（空备份就中止）。
3. 装包：`adb install -r dist/english-app-1.4.5.apk`（只覆盖，不清数据）。
4. 填地址：把电脑启动窗口那行整行粘进「我的 → 卡背结构地址」：
   `http://10.105.85.227:8765#<22 位口令>`（1.4.5 会自动拆出令牌）。
5. 真点一次重写，验四条：卡背换文 + 方法标签出现；电脑日志出现 `POST /rewrite/marks`；`/rewrite/status` 的 `seq`/`done` 各 +1；`tb_progress` 行数与装机前一致。

现成脚本：`_recon/fix-rewrite-145.sh <serial>`（取证→备份→装→打印要粘的那行，含 `--dry-run`，不含任何清数据命令）；`_recon/smoke-rewrite.sh`（点完自动判通没通）。

## 怎么杜绝（分三层，按性价比排）

**L1 让用户 3 秒看懂（手机端，约 20–40 行/条）**

| # | 做法 | 成本 |
|---|---|---|
| 1 | 地址栏下面显示「上次连接：18:46 成功 · 电脑 10.105.85.227」/「失败 · 连不上 10.105.85.173」 | ~20 行 |
| 2 | 连不上时文案直接说「电脑换过网络地址会变，去电脑窗口看那行 IP」（已做一半） | 已做 |
| 3 | 设置里加「自动找电脑」：手机 UDP 广播，电脑回自己的地址 | 两端 60–80 行；**唯一根治 DHCP 换 IP** |

**L2 让电脑端自己报警（改完要重启一次 server.py）**

4. 启动自检一行：口令位数 / `/models` 200 / 待重写数 / 手机连过几次；失败给下一步。
5. IP 变更侦测：启动时和上次比，变了就红字提示「手机要重粘这一行」，编辑器首页常驻红条。
6. 编辑器首页加「手机连接」状态灯（等待连接 / 已连 3 次）。
7. `/rewrite/status` 返回 `auth` + 当前 IP + 口令前缀，手机就能区分「被当外人」和「网络断了」。

**L3 发版拦住**

8. 发版清单加「真机重写冒烟」，三条同时满足才许发（日志有 marks / seq+1 / 卡背换文）。
9. release note 写明「先升手机、后升电脑；连不上先看电脑窗口那行 IP 是不是今天的」。
10. 口令轮换说明：删 `.cardback_token` 重启会生成新口令，**手机必须重粘那一行**。
