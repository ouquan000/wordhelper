# 1.4.5 升级公告

## 这版你能感觉到的东西

1. **翻卡不再顿一下。** 之前翻到背面时，整页内容是「翻到一半才开始画」，所以会卡一下。现在正反两面一直备着，翻起来是顺的；背面滚动也更稳，不会误触到背面的按钮。
2. **电脑那边只用粘一行。** 启动电脑端服务后，窗口里会打印一行：
   `手机：粘贴这一行 → http://192.168.x.x:8765#<口令>`
   手机上「我的 → 卡背结构地址」把这一整行粘进去就行，口令自己带上了；原来那个单独的口令输入框删掉了。老用户之前填过的地址照旧能用。
3. **每本书的思路各管各的。** 在「测试·20 词」里重写一个词的记忆思路，不会再改到「六级记忆卡」里的同一个词；卡背先显示这本书自己的思路，这本书没改过才显示全局的。撤销也只撤这本书的。
4. **切到「当前词书」终于有图了。** 学习统计右上角切到「当前词书」，会显示这本书过去一周的新词/复习曲线，配 5 个按书指标。**这本书的曲线从升级这天开始记**，之前的历史没有按书拆分，所以头几天是空的，不是坏了。
5. **学习记录会自己备份。** 每次回到 App 前台，只要手机和电脑在同一个 WiFi、电脑端服务开着，就会静默把新的学习记录传过去（5 分钟内不重复传）。数据管理里手动按钮和「已同步 N 条」的回执还在。

## 升级注意

- 覆盖安装就行，**学习进度不会丢**；首次打开会做一次数据库升级（16 → 17），几秒钟，别急着杀进程。
- 电脑端 `server.py` 要**重启一次**，才会打印新的「手机：粘贴这一行」。
- 之前填过旧地址（只有 IP、没有 `#口令`）的，不用重填——口令还单独存着，继续能用；想换成新格式就粘一次整行。

## 仍然没有的（别当成 bug）

- 按书视图只能看「当前词书」，还没有书目下拉；要看别的书先切当前词书。
- 按书连续打卡天数仍是全局口径。
- 自动备份只在同一 WiFi、电脑端开着时生效；不满足就静默跳过，不报错。
- 翻面的「手感」只能在真机上看，模拟器看不出差别。
